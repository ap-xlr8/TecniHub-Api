# Organización del equipo

La organización contempla responsabilidades y no representa cuentas ficticias. Hoy hay una sola persona; los roles siguientes pueden recaer temporalmente en ella.

| Rol | Responsabilidades y actividades | Entregables / relación |
|---|---|---|
| Líder técnico / arquitectura | Límites de capas, decisiones, priorización técnica | ADR/documentación; coordina con los otros roles |
| Backend | API, casos de uso, persistencia e integraciones aprobadas | Código y pruebas; acuerda contratos con frontend |
| Frontend | Angular, PWA y consumo del contrato API | Interfaz y pruebas; coordina rutas/configuración con backend |
| QA / DevSecOps | CI, calidad, seguridad y evidencias | Resultados reproducibles; habilita criterios para ambos repositorios |

No se simulan asignaciones, PR reviews ni aprobaciones independientes.
